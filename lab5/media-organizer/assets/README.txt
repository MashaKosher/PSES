MEDIA ORGANIZER ASSETS
======================

Place the following files in this folder:

GIF FILES (required):
- corner1.gif    - Top-left corner GIF
- corner2.gif    - Top-right corner GIF  
- corner3.gif    - Bottom-left corner GIF
- corner4.gif    - Bottom-right corner GIF
- no_signal.gif  - "No programs" / static screen GIF

AUDIO FILES (required):
- track.mp3      - Main audio track to play
- noise.mp3      - Background static/interference sound

IR REMOTE CONTROL MAPPING:
--------------------------
0x20DF8877 - Toggle corner 1 (top-left)
0x20DF48B7 - Toggle corner 2 (top-right)
0x20DFC837 - Toggle corner 3 (bottom-left)
0x20DF28D7 - Toggle corner 4 (bottom-right)
0x20DFA857 - Play/Pause track
0x20DF6897 - Reset track to start

KEYBOARD SHORTCUTS (for testing):
---------------------------------
1-4    - Toggle corner GIFs
Space  - Play/Pause track
R      - Reset track
Esc    - Quit application
